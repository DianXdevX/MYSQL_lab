## 🧠 Conceitos e Comandos Praticados

Ao longo destes laboratórios, venho desenvolvendo e aplicando os seguintes conceitos de banco de dados relacional:

*   **DDL (Data Definition Language):** Estruturação do banco (`CREATE DATABASE`, `CREATE TABLE`, `ALTER TABLE`, `DROP`).
*   **DML (Data Manipulation Language):** Manipulação de registros (`INSERT INTO`, `UPDATE`, `DELETE`).
*   **DQL (Data Query Language):** Consultas personalizadas e filtros avançados (`SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`, `HAVING`).
*   **Relacionamentos e Junções:** Integração de tabelas com chaves primárias (`PK`), chaves estrangeiras (`FK`) e junções inteligentes (`INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`).
*   **Modelagem de Dados:** Normalização de tabelas (1FN, 2FN, 3FN) e criação de diagramas conceituais e lógicos.
